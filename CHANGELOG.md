# Changelog

## 0.1.0

- Initial game UI created.
- Overview page showing club information.
- Squad page with Attributes, Statistics and Contract information for players.
- Tactics screen with initial formations, mentality and substitutions. Ability to create custom tactic by moving players on the tactics screen.
- Basic training summary screen.
- Basic fixtures screen showing demo fixtures.
- Competitions page displaying the league table, including the Premier League and Championship. Tabs for cup competitions.
- Inbox for news and messages.
- Transfers page showing team transfers.
- Scouting hub page.
- Finances hub page.
- Staff hub page.
- Manager summary page.
- Simulated match engine showing demo game of Chelsea v Manchester United.
- New game screen to allow a team to be selected, having displayed team/club information, and add a manager name. The user is then taken to the inbox where the chairman will provide a welcome message and the inbox will display a news article announcing the appointment.
